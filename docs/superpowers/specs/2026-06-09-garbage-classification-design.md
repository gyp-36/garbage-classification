## 5. 训练配置

| 参数 | 值 | 说明 |
|------|-----|------|
| 图像尺寸 | 224 × 224 | EfficientNet 标准输入 |
| Batch Size | 32 | GPU 显存足够可增大 |
| 初始学习率 | 3e-4 | AdamW 推荐范围 |
| 优化器 | AdamW | 带权重衰减 |
| 训练轮次 | 50 epochs | 或早停触发 |
| 数据划分 | 70% / 15% / 15% | 训练/验证/测试 |
| 预训练 | ImageNet | timm 官方权重 |
| 损失函数 | CrossEntropyLoss | 多分类标准 |
| 数据增强 | RandomFlip, RandomCrop, ColorJitter | 防止过拟合 |
